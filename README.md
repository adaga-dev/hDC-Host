# hDC Host 🌐

Projeto de **landing page com responsividade** para uma empresa fictícia de hospedagem de sites chamada **hDC Host**. O objetivo é apresentar planos de hospedagem, serviços, busca de domínio e formulário de contato utilizando **HTML5 e CSS3**.

---

## Funcionalidades

- Navbar com links e botão para fazer login no site;
- Banner com nome da empresa e chamada de marketing;
- Seção com os serviços oferecidos pela empresa;
- Tabela de preços, com o plano recomendado em destaque com outra cor;
- Busca de domínio (layout);
- Formulário de contato;
- Design responsivo para desktop, tablet e mobile.

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **Font Awesome** (para ícones)

---

## Responsividade

O site foi desenvolvido com **media queries**, garantindo boa experiência em:

- 💻 Desktop
- 📱 Celulares
- 📲 Tablets

## Relatório de Aprendizado

Durante o desenvolvimento deste projeto, pude consolidar os seguintes aprendizados:

### HTML

- Estruturação semântica do site (`header`, `nav`, `main`, `section`, `footer`)
- Criação de **formulários** com `input`, `textarea` e `submit`
- Organização de conteúdo em listas e seções
- Boas práticas de indentação e legibilidade do código

### CSS

- Estilização completa de layouts
- Uso de **Flexbox** para alinhamento e distribuição de elementos
- Criação de componentes reutilizáveis (botões, cards de planos)
- Trabalhar com cores, fontes, espaçamentos e hierarquia visual

### Responsividade

- Uso de **Media Queries** para diferentes tamanhos de tela
- Adaptação do layout para:
  - Desktop
  - Tablet
  - Dispositivos móveis

- Ajuste de formulários, menus e grids para telas menores

Este projeto marcou um avanço importante na minha evolução em **Front-end**, especialmente no entendimento de como criar interfaces responsivas e bem estruturadas apenas com HTML e CSS.
